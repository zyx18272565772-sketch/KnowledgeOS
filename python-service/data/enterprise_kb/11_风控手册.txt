# 悦购电商 · 风控管理手册

## 一、风控目标

风控团队负责防范平台欺诈行为，保护商家和平台利益。核心场景：刷单、恶意退款、账号盗用、支付欺诈、虚假交易。

## 二、主要风险场景

### 2.1 刷单/虚假交易
- 特征：同一用户短时间内大量下单、收货地址异常、无真实物流。
- 识别：下单频率、收货地址、支付方式、设备指纹多维度识别。
- 处理：风控标记、限制参与活动、封禁账号。

### 2.2 恶意退款
- 特征：频繁退换、退货金额与运费不匹配、利用规则漏洞。
- 识别：退款率超阈值、退换频率、与客服历史。
- 处理：限制退款特权、标记高风险用户。

### 2.3 账号盗用
- 特征：异地登录、设备变化、异常修改绑定信息。
- 识别：登录行为、设备指纹、风控规则。
- 处理：触发二次验证、冻结账号。

### 2.4 支付欺诈
- 特征：盗刷、拒付（Chargeback）。
- 识别：支付风控规则（金额、频次、设备）。
- 处理：拦截高风险支付、人工审核。

## 三、风控策略

### 3.1 规则引擎
- 基于规则（如"同设备 1 小时下单 > 5 单"触发拦截）。
- 规则可配置、可灰度、可回滚。

### 3.2 模型评分
- 用户风险分：基于行为特征打分，高风险用户拦截/审核。
- 设备风险分：识别异常设备。

### 3.3 人工审核
- 规则/模型判定高风险 → 人工审核队列。
- 审核员查看订单、用户、设备信息，决定放行/拦截。

## 四、风控流程

1. 用户行为触发风控规则/模型。
2. 判定等级：通过 / 拦截 / 人工审核。
3. 拦截订单进入审核队列。
4. 人工审核或自动放行（低风险灰度）。
5. 处理结果记录，反哺风控规则优化。

## 五、风控与业务的平衡

- 风控过严会误伤正常用户（体验差），过松会纵容欺诈（损失大）。
- 策略：**高风险全拦截，中风险人工审核，低风险放行观察**。
- 定期复盘拦截率、误伤率，调优阈值。

## 六、常见问题

Q：用户被误判刷单怎么办？
A：用户申诉 → 人工复核 → 确认正常则解封，并反哺规则降低误伤。

Q：大促期间刷单变多怎么办？
A：大促前上线专项风控规则（提高下单频次阈值），风控团队 7×24 值班。
